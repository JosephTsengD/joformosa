## 驗收條件

Scenario: SessionStatus
  Given 一場 19:30 開始、21:00 結束的活動
  When  以不同時間點查詢狀態
  Then  48 小時前為 scheduled，12 小時前為 imminent
  And   開始瞬間為 ongoing，結束瞬間為 past
  And   沒有 endsAt 時預設為開始後 2 小時

Scenario: Pagination
  Given 資料庫有超過一頁的已發佈社團
  When  使用者連續捲動到底
  Then  所有 id 不重複
  And   最後一頁的 nextCursor 為 null

Scenario: FilterUrlSync
  Given 一組包含運動、縣市、風格、關鍵字與排序的篩選
  When  轉成 query params 後再轉回
  Then  所有欄位與原本相同

Scenario: RelativeTime
  Given 使用者在 23:00 檢視一場隔日 01:00 的活動
  When  格式化相對時間
  Then  顯示「明天」而非「今天」

Scenario: AppBoots
  Given 使用者第一次開啟 App
  When  探索頁載入完成
  Then  渲染出社團卡片且不拋任何例外
  And   後端失敗時顯示錯誤狀態與重試按鈕
  And   沒有結果時顯示空狀態文案
  And   深色模式下整棵 widget 樹不拋錯
  And   首次進入時顯示示範資料橫幅
  And   搜尋框存在，輸入後能篩出結果，落空時顯示含關鍵字的空狀態

Scenario: Degradation
  Given 真實後端不可用（網路錯誤或逾時）
  When  使用者瀏覽列表或詳情
  Then  讀取降級到本地合成資料且顯示提示條
  And   找不到資料、被 RLS 擋下等業務結果**不**觸發降級
  And   寫入操作永不降級，失敗必須誠實回報

Scenario: NoGlobalNavState
  Given 同一個 process 內先後啟動兩次 App
  When  第一次留下了搜尋狀態
  Then  第二次啟動回到乾淨的初始狀態
  And   測試結果不因執行順序而改變

Scenario: EmptyStateFits
  Given 空狀態畫面
  When  在手機橫向、小螢幕、2.0 字級等極端組合下渲染
  Then  不產生版面溢位
  And   空間不足時內容可捲動，而不是被裁掉

Scenario: CardStates
  Given 一張社團卡片
  When  社團在 30 天內建立
  Then  顯示 NEW 徽章
  And   沒有活動時顯示「尚未公告本月活動」
  And   超長名稱單行省略且不溢位
  And   textScaleFactor 2.0 時不破版

## 不做什麼
- 不做搜尋框（T-050）
- 不做距離排序與地圖（T-061）
