## 驗收條件

Scenario: Idempotency
  Given 團長填好社團登錄表單
  When  以相同 idempotencyKey 送出兩次（模擬網路重試）
  Then  只產生一筆社團資料
  And   兩次都回傳同一個 crew id

Scenario: UnsavedGuard
  Given 團長已修改表單但未送出
  When  按下關閉
  Then  顯示未儲存警告對話框

Scenario: Honeypot
  Given 機器人填寫了隱藏欄位
  When  送出表單
  Then  回傳假成功且不寫入資料庫

Scenario: DemoPersistence
  Given 示範模式（無後端）
  When  使用者送出社團並新增活動，然後重新整理頁面
  Then  資料仍在，且每個瀏覽器彼此隔離
  And   按下重置後回到初始狀態，種子資料不受影響
  And   本地儲存內容毀損時安全降級為空，不讓畫面壞掉

## 不做什麼
- 不做圖片上傳（T-063）
- 不做認領既有社團流程（T-065）
