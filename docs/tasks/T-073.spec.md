## 問題

看到活動之後沒有下一步。而且新手最大的猶豫是「會不會只有我一個人去」，
人數是最有效的社交證明。

## 技術決定

`rsvps` 表已存在且以 `(user_id, session_id)` 為複合主鍵——
**冪等性寫在 schema 裡**，連點五次只會有一筆。

## 驗收條件

Scenario: RsvpOptimistic
  Given 使用者點擊「我要參加」
  When  網路請求尚未回應
  Then  按鈕立即變成已參加、人數加一
  And   請求失敗時完整回滾（狀態與人數都復原）並顯示錯誤

Scenario: RsvpIdempotent
  Given 使用者在一秒內連點五次
  When  所有請求都送達
  Then  資料庫只有一筆記錄
  And   顯示人數只增加一

Scenario: RsvpRequiresAuth
  Given 未登入的訪客
  When  點擊「我要參加」
  Then  導向登入頁
  And   登入後自動完成原本的 RSVP，不需要再點一次

Scenario: RsvpPastSession
  Given 一場已結束的活動
  When  畫面渲染
  Then  不顯示 RSVP 按鈕，改顯示參加人數的歷史值

## 不做什麼
- 不做人數上限與候補（真實社團多半不限額）
- 不做參加者名單（隱私）
- 不做報到打卡
